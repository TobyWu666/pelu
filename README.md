# Pelu

A small system that lets your iPhone see real-time Claude Code and Codex usage from one or more paired Macs — without calling the Anthropic / OpenAI APIs or scraping any web UI.

```
[Claude Code / Codex writes local files on Mac]
              ↓
[PeluMac reads files → uploads envelope]
              ↓
[Cloudflare Worker: per-Mac KV + APNs push]
              ↓
[iPhone app / Widget / Live Activity]
```

## Components

| Path | Role |
|---|---|
| `Sources/PeluCore/` | Shared Swift package: models, parsers, Keychain wrapper, App Group cache, cloud client. |
| `Sources/PeluUI/` | Shared SwiftUI components (dashboard view, status pill, theme). |
| `Apps/Pelu/` | iOS app — pairing screen, multi-Mac dashboard, settings (notifications / Live Activity / unpair). |
| `Apps/PeluMac/` | macOS menu bar app — reads `~/.claude/usag-status.json` + `~/.codex/sessions/*.jsonl`, auto-installs the Claude Code statusLine hook on first launch, uploads to the Worker. |
| `Apps/PeluWidget/` | iOS Widget (small + medium) and Live Activity (lockscreen + Dynamic Island). |
| `Cloudflare/` | Worker source (`src/index.ts`), per-Mac KV storage, APNs token-based push, 6-digit pairing flow. |
| `Tests/PeluCoreTests/` | Swift Testing suite for parsers, Codable round-trip, cloud client, AppGroup store. |

## How it works

### Mac side
1. PeluMac launches, auto-installs the Claude Code statusLine hook (`~/.claude/usag-statusline.py`) so Claude Code persists each session's JSON to `~/.claude/usag-status.json`.
2. FSEvents watches that file plus a 60s timer scans `~/.codex/sessions/*.jsonl` for the latest `token_count` event.
3. Every minute Mac uploads a `{ macId, label, generatedAt, metrics }` envelope to `POST /usage`, authenticated by the admin shared secret stored in macOS Keychain.

### iPhone side
1. First launch shows a pairing screen. Mac's menu bar has a button to mint a 6-digit code; user types it on iPhone to claim a per-device pair token via `POST /pair/claim`. Token is stored in iOS Keychain.
2. Dashboard pulls `GET /usage` → renders one section per Mac (label + Claude Code card + Codex card).
3. Worker fires a silent APNs background push whenever any Mac's metrics actually change; iPhone wakes briefly, re-fetches, reloads the widget timeline.
4. Two optional alert notifications: low-quota warning (>90% used) and reset notification.

### Auth model
- **Admin secret** — only used by Mac → Worker uploads. Stored in macOS Keychain (seeded once from a gitignored `PeluMacConfig.swift`).
- **Pair token** — per-iPhone, generated by Worker on `/pair/claim`, stored in iOS Keychain. Used for `GET /usage` and `/device` calls.

## Build & test

Requires the full Xcode toolchain (not just Command Line Tools).

```sh
# Swift package (PeluCore + PeluUI)
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift build

# Apps
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project Pelu.xcodeproj -scheme Pelu -destination 'generic/platform=iOS Simulator' build
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project Pelu.xcodeproj -scheme Pelu -destination 'generic/platform=iOS' build
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project Pelu.xcodeproj -scheme PeluMac -destination 'generic/platform=macOS' build

# Cloudflare Worker
cd Cloudflare && npm test
cd Cloudflare && npx wrangler deploy --dry-run
```

## Packaging the Mac app

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild \
  -project Pelu.xcodeproj -scheme PeluMac \
  -configuration Release -derivedDataPath ./build-release \
  -destination 'generic/platform=macOS' \
  CODE_SIGN_IDENTITY="-" CODE_SIGNING_REQUIRED=NO CODE_SIGNING_ALLOWED=NO \
  clean build
```

Output: `build-release/Build/Products/Release/PeluMac.app`. Ad-hoc signed; first launch needs **right-click → Open** to satisfy Gatekeeper.

## First-time setup

1. **Cloudflare**
   ```sh
   cd Cloudflare
   wrangler kv namespace create PELU_USAGE_KV    # if not already
   wrangler secret put PELU_SHARED_SECRET        # paste a strong random string
   # Then the APNs secrets — see Cloudflare/README.md
   wrangler deploy
   ```
2. **PeluMacConfig.swift** (gitignored): set `bootstrapSecret` to the same value you put in `PELU_SHARED_SECRET`.
3. Build + launch PeluMac on each Mac. The auto-installer adds the Claude Code statusLine hook on first run.
4. Build + launch iOS app. Mac menu bar → tap the iPhone icon → enter the 6-digit code on the phone.

## Multi-Mac

Each Mac mints its own UUID on first launch (stored in macOS Keychain as `pelu.macId`) and uses its hostname (`Host.localizedName`) as the display label. Worker stores snapshots per-Mac under `usage:{macId}`. iPhone dashboard renders one section per Mac. Widget and Live Activity show the alphabetically-first Mac as "primary" (selectable primary is a future enhancement).

## Notes & limits

- Mac app is ad-hoc signed; users see a Gatekeeper warning the first time. Use right-click → Open, or notarize with a paid Developer ID if distributing.
- iOS app is not on the App Store — install via Xcode to a real device.
- APNs runs in `development` mode by default. Switch the Worker secret `APNS_ENVIRONMENT` to `production` AND the iOS entitlement `aps-environment` to `production` before shipping to TestFlight / App Store, otherwise pushes won't reach.
- The pair token leakage model is single-user; multi-user pairing with revocation isn't built.
